# EPCS_net_repo

Code and results for EPCS-Net (SAM-guided multi-scale nuclei segmentation).

| Folder | Content |
|---|---|
| `EPCS_Revised_2/` | **Current version** (second revision of the paper): code, per-run results, master results workbook, checkpoint manifest. Start with `EPCS_Revised_2/README.md`. |
| `EPCS_Revised/` | Earlier revision (kept unchanged). |
| `cryonuseg/`, `nuinseg/` | Original submission code (kept unchanged). |

Numbers in `EPCS_Revised_2/` replace those of the earlier folders.
